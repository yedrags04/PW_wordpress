A versatile and responsive slider plugin for WordPress, offering customizable sliders for images, content, and more.

== Description ==

The **Multi Builder Slider ** is a powerful and flexible solution for creating stunning sliders and carousels on your WordPress site. Whether you need to showcase images, testimonials, or dynamic content, this plugin provides a user-friendly interface and a wide range of customization options to fit your needs.

[ View Demo ](https://craftedbyaman.rf.gd/multi-builder-slider/)

**Features:**
- **Fully Customizable:** Tailor your sliders with customizable settings for layout, animation, and design.
- **Responsive Design:** Ensures your sliders look great on all devices, from desktops to mobiles.
- **Multiple Slider Types:** Choose from image sliders, content sliders and more.
- **Drag-and-Drop Builder:** Easily create and manage sliders using the intuitive block editor.
- **Autoplay and Loop:** Enable autoplay and infinite looping for a seamless user experience.


== Installation ==

1. **Upload Plugin:**
   - Download the plugin ZIP file.
   - Go to the WordPress admin dashboard.
   - Navigate to **Plugins > Add New**.
   - Click **Upload Plugin** and select the ZIP file.
   - Click **Install Now**.

2. **Activate Plugin:**
   - After installation, click **Activate Plugin**.


== Usage ==
Multi Builder Slider
1. **Adding a Slider:**
   - Go to the WordPress block editor for the page or post where you want to add the slider.
   - Click the **Add Block** button (usually a plus sign) and search for "Multi Builder Slider".
   - Select the slider block and configure its settings.

2. **Configuring Sliders:**
   - Customize the slider’s appearance, animation, and behavior using the block editor’s sidebar options.
   - Add slides by uploading images, or adding custom content.

3. **Saving Changes:**
   - Once configured, click **Update** or **Publish** to save changes and display the slider on your site.

== Frequently Asked Questions ==

= What types of content can I add to the slider? =
You can add images, text, and even custom HTML content to your sliders.

= Is the plugin compatible with all themes? =
Yes, the plugin is designed to work seamlessly with most WordPress themes. If you encounter any issues, ensure your theme is updated to the latest version.

= Can I use multiple sliders on the same page? =
Absolutely! You can add and configure as many sliders as you need on a single page or post.

= How do I update the plugin? =
To update the plugin, go to **Plugins** in your WordPress admin dashboard. If an update is available, you will see a notification. Click **Update Now** to get the latest version.
